Marking scheme

    Sections

      Answering and navigation

      • One question is shown at a time. Select an option, then press Save & Next to save it. A selection is not saved until you press Save & Next or Mark for Review & Next.
      • You can change a saved answer at any time: open the question, choose another option and press Save & Next again.
      • Clear Response removes the saved answer of the current question.
      • Previous and the numbered question palette let you move to any question. Moving away without saving discards an unsaved selection.
      • The message under the options tells you when the server has confirmed an answer ("Saved at …"). If your connection drops, the page retries and tells you clearly if an answer could not be saved.

      Marking questions for review

      • Mark for Review & Next flags a question so you can return to it. If an option is selected, the answer is also saved.
      • Questions that are answered and marked for review are evaluated.
      • Palette colours: Not visited Not answered Answered Marked for review Answered & marked

      Time limit

      • The timer starts only when you press Start Examination. It is controlled by the server, so refreshing the page, closing the browser or changing your computer's clock does not stop or extend it.
      • When the time reaches zero, your test is submitted automatically. Only answers already saved on the server are counted.

      Leaving the examination window

      • Stay on this test tab until you submit. Switching to another tab or application, minimising the browser or leaving full-screen mode is recorded with the time and is visible to the HR team.
      • You will see a warning each time it happens.
      • No camera, microphone or screen recording is used. Only these browser events are recorded.

      One attempt only

      • You can take this test once. Once you press Start Examination your attempt has begun, even if you close the browser.
      • If you get disconnected, log in again with the same details to continue the same attempt with the remaining time.
      • After you submit, you will see a confirmation only. Scores are not shown to candidates; HR will contact you about next steps.
